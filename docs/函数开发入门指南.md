# 函数开发入门指南

这份文档写给完全没有编程经验的同学。你不需要理解整个项目，只要知道：比赛现场大多数题目，都可以通过“调用已有函数”或“新增一个自己的函数”完成。

## 0. 最推荐的零基础入口：easy_api.py

现在已经提供了一套最简单的函数封装，文件是：

```text
starter/easy_api.py
```

上传 `starter/` 到板子后，在 Thonny REPL 里输入：

```python
from easy_api import *
```

然后就可以像下面这样调用：

```python
init()

guangmin(1)             # 启用光敏
i = readguangmin()      # 读取光敏原始值

anjian(1)               # 启用按键
event = waitanjian()    # 等待任意按键

led(1)                  # 启用 LED
setled("red", 1)        # 点亮红灯
```

也就是说，初学者优先使用 `easy_api.py`；只有需要写复杂组合逻辑时，再去看 `universal_main.py`。

### 按键封装重点

按键名称固定为：

```text
user, up, down, left, right, center
```

事件名称固定为：

```text
press, release, short, long, repeat
```

最常用写法：

```python
from easy_api import *

anjian(1)

event = waitanjian()
if event:
    name, action = event
    print(name, action)
```

等待中心键短按：

```python
event = waitkey("center")
```

等待任意长按：

```python
event = waitlong()
```

## 1. 先理解：什么是函数

函数就是一段可以重复使用的代码。它通常做三件事：

1. 接收输入。
2. 执行动作。
3. 返回结果。

最简单的函数长这样：

```python
def say_hello():
    print("hello")
```

运行它：

```python
say_hello()
```

带参数的函数：

```python
def add(a, b):
    return a + b

result = add(1, 2)
print(result)
```

这里：

- `def` 表示“定义一个函数”。
- `add` 是函数名。
- `a, b` 是参数。
- `return` 表示返回结果。

## 2. 这个项目里最重要的几个文件

你平时主要看这几个文件：

| 文件 | 作用 | 初学者是否经常改 |
|---|---|---|
| `starter/config.py` | 配置功能开关、引脚、串口号 | 经常改 |
| `starter/main.py` | 板子启动入口 | 一般不改 |
| `starter/universal_main.py` | 通用命令入口，适合加自己的功能 | 经常改 |
| `starter/lib/kit/` | 已经写好的底层功能库 | 尽量少改 |

最推荐的做法：

- 改配置：改 `config.py`。
- 加功能：改 `universal_main.py`。
- 不熟悉时：不要改 `lib/kit/` 里的底层库。

## 3. 如何调用已有函数

打开 Thonny 的 REPL，输入：

```python
from universal_main import UniversalKit

app = UniversalKit()
app.help()
```

这会显示所有可用命令。

运行单个功能：

```python
app.run("adc")
```

运行全部功能：

```python
app.run_all()
```

常用命令：

```python
app.run("preflight")     # 检查固件模块
app.run("led")           # LED
app.run("button_led")    # 按键控制 LED
app.run("adc")           # 光敏 ADC
app.run("i2c")           # I2C 扫描
app.run("sensors")       # 温湿度/加速度
app.run("timer")         # 定时器
app.run("uart")          # 串口回环
app.run("storage")       # 存储测试
```

## 4. 如何看已有函数的结果

项目统一使用三种结果：

```text
PASS  成功
FAIL  失败
SKIP  跳过
```

例如：

```text
[TEST][ADC][PASS] raw=22277 voltage=1.12 percent=34.0
[TEST][PWM][SKIP] set PWM_OUTPUT_PIN/PWM_MEASURE_PIN
[TEST][UART][FAIL] sent=b'QUECTEL-UART' recv=b''
```

判断方法：

- `PASS`：不用管，功能已成功。
- `SKIP`：没有打开功能，或者没有配置引脚。
- `FAIL`：代码运行了，但接线、硬件、配置或固件有问题。

## 5. 如何写自己的普通函数

先从最简单的开始。比如你想打印一行文字：

```python
def my_message():
    print("This is my test")
```

如果想返回结果：

```python
def get_number():
    return 123

value = get_number()
print(value)
```

如果想让函数接收参数：

```python
def blink_message(name):
    print("testing", name)

blink_message("LED")
```

注意：Python 用缩进表示代码属于哪个函数。函数里面的代码必须缩进，通常缩进 4 个空格。

## 6. 如何写一个比赛用自定义功能

推荐在 `starter/universal_main.py` 的 `UniversalKit` 类里面加函数。

函数名必须用这个格式：

```python
def cmd_你的命令名(self):
    ...
```

例如，新增一个命令 `hello`：

```python
def cmd_hello(self):
    print("hello competition")
    return self.reporter.passed("HELLO", "custom command ok")
```

然后在 Thonny REPL 里运行：

```python
from universal_main import UniversalKit
app = UniversalKit()
app.run("hello")
```

输出：

```text
[TEST][HELLO][PASS] custom command ok
```

## 8. 自定义函数如何调用 LED

示例：点亮第一个 LED 1 秒。

```python
def cmd_my_led(self):
    if not self.runtime.leds:
        return self.reporter.skipped("MY_LED", "LED not initialized")

    name = self.runtime.leds.names()[0]
    self.runtime.leds.on(name)
    sleep_ms(1000)
    self.runtime.leds.off(name)

    return self.reporter.passed("MY_LED", name)
```

注意：这个函数用到了 `sleep_ms`，所以文件顶部要有：

```python
from lib.kit.compat import sleep_ms
```

## 9. 自定义函数如何读取 ADC

如果想读取光敏电阻，可以直接用已有快照：

```python
def cmd_my_light(self):
    data = self.runtime.snapshot()
    light = data.get("sensors", {}).get("light")

    if not light:
        return self.reporter.failed("MY_LIGHT", "no light data")

    raw = light["raw_u16"]
    voltage = light["voltage"]
    percent = light["percent"]

    detail = "raw={} voltage={:.2f} percent={:.1f}".format(raw, voltage, percent)
    return self.reporter.passed("MY_LIGHT", detail)
```

运行：

```python
app.run("my_light")
```

## 10. 自定义函数如何读取 I2C

扫描 I2C 地址：

```python
def cmd_my_i2c(self):
    data = self.runtime.snapshot()
    i2c = data.get("sensors", {}).get("i2c")

    if not i2c:
        return self.reporter.failed("MY_I2C", "no i2c data")

    addresses = i2c.get("addresses", [])
    text = ",".join(hex(x) for x in addresses)
    return self.reporter.passed("MY_I2C", text)
```

正常情况下，可能看到：

```text
0x19,0x38
```

## 11. 自定义函数如何做 GPIO 输出

如果题目要求控制一个 GPIO 高低电平，可以直接使用 `machine.Pin`：

```python
def cmd_my_gpio_out(self):
    import machine

    pin = machine.Pin("D2", machine.Pin.OUT)
    pin.value(1)
    sleep_ms(500)
    pin.value(0)

    return self.reporter.passed("MY_GPIO_OUT", "D2 high then low")
```

注意：`"D2"` 要换成题目给你的实际引脚。

## 12. 自定义函数如何读 GPIO 输入

例如读取 `D3`：

```python
def cmd_my_gpio_in(self):
    import machine

    pin = machine.Pin("D3", machine.Pin.IN, machine.Pin.PULL_DOWN)
    value = pin.value()

    return self.reporter.passed("MY_GPIO_IN", "D3={}".format(value))
```

如果你把 `D2` 接到 `D3`，就可以一个输出、一个输入做回环测试。

## 13. 自定义函数如何调用已有 GPIO 回环

如果你不想自己写高低电平逻辑，可以直接调用已有类：

```python
from lib.kit.io_tests import GpioLoopback

    ok, detail = GpioLoopback("D2", "D3").run()

    if ok:
        return self.reporter.passed("MY_GPIO_LOOP", detail)
    return self.reporter.failed("MY_GPIO_LOOP", detail)
```

这要求用杜邦线把 `D2` 和 `D3` 短接。

## 14. 自定义函数如何调用 UART

已有 UART 回环函数：

```python
from lib.kit.serial_tests import UartPort

def cmd_my_uart(self):
    uart = UartPort(2, 115200, 1000)
    ok, detail = uart.loopback(b"HELLO")

    if ok:
        return self.reporter.passed("MY_UART", detail)
    return self.reporter.failed("MY_UART", detail)
```

注意：

- 需要 TX 接 RX。
- `2` 是 UART 编号。
- `115200` 是波特率。

## 15. 自定义函数如何调用 PWM

PWM 建议用已有安全封装，不要直接乱开输出：

```python
from lib.kit.io_tests import PwmOutput, PulseMeter

def cmd_my_pwm(self):
    pwm = None
    meter = None
    try:
        pwm = PwmOutput("D5", 1000, 50)
        pwm.start()

        meter = PulseMeter("D6")
        ok, detail = meter.sample(500)

        if ok:
            return self.reporter.passed("MY_PWM", detail)
        return self.reporter.failed("MY_PWM", detail)
    finally:
        if meter:
            meter.close()
        if pwm:
            pwm.stop()
```

注意：

- 用杜邦线把 `D5` 接到 `D6`。
- `1000` 表示 1 kHz。
- `50` 表示 50% 占空比。
- `finally` 非常重要，可以确保测试失败时 PWM 也会关闭。

## 17. 自定义函数的标准模板

写比赛函数时，建议统一用这个模板：

```python
def cmd_my_test(self):
    if not self.config.FEATURES.get("某功能"):
        return self.reporter.skipped("MY_TEST", "disabled")

    try:
        # 1. 初始化硬件
        # 2. 执行测试
        # 3. 判断结果
        ok = True
        detail = "some detail"

        if ok:
            return self.reporter.passed("MY_TEST", detail)
        return self.reporter.failed("MY_TEST", detail)

    except Exception as exc:
        return self.reporter.failed("MY_TEST", exc)
```

这样写的好处：

- 功能关闭时不会误报失败。
- 出错时能看到原因。
- 输出格式和裁判程序一致。

## 18. 什么时候改 config.py，什么时候写函数

只改 `config.py` 的情况：

- 换 GPIO 引脚。
- 换 UART 编号或波特率。
- 打开/关闭某个功能。
- 填 PWM 输出脚、测量脚。
- 填 RS485 方向控制脚。

需要写函数的情况：

- 题目要求一个新的动作组合。
- 题目要求按键控制多个外设。
- 题目要求读取传感器后做判断。
- 题目要求串口收到某个数据后控制 LED 或蜂鸣器。

## 19. 一个完整例子：光线太暗就亮 LED

题目可能要求：读取光敏电阻，如果光线低于某个值，就点亮 LED。

可以在 `UniversalKit` 里加：

```python
def cmd_dark_led(self):
    if not self.runtime.leds:
        return self.reporter.skipped("DARK_LED", "LED not initialized")

    data = self.runtime.snapshot()
    light = data.get("sensors", {}).get("light")
    if not light:
        return self.reporter.failed("DARK_LED", "no light data")

    percent = light["percent"]
    led_name = self.runtime.leds.names()[0]

    if percent < 30:
        self.runtime.leds.on(led_name)
        action = "led on"
    else:
        self.runtime.leds.off(led_name)
        action = "led off"

    return self.reporter.passed(
        "DARK_LED",
        "light={:.1f}% {}".format(percent, action)
    )
```

运行：

```python
app.run("dark_led")
```

## 20. 一个完整例子：按键触发蜂鸣器

题目可能要求：按下用户键，蜂鸣器响一下。

```python
def cmd_button_buzzer(self):
    if not self.runtime.buttons:
        return self.reporter.skipped("BUTTON_BUZZER", "buttons not initialized")
    if not self.config.BUZZER_PIN:
        return self.reporter.skipped("BUTTON_BUZZER", "BUZZER_PIN not set")

    print("Press user key")
    start = ticks_ms()

    while ticks_diff(ticks_ms(), start) < 10000:
        for name, event in self.runtime.buttons.poll(ticks_ms()):
            if name == "user" and event == "short":
                Buzzer(self.config.BUZZER_PIN, self.config.BUZZER_ACTIVE).beep(300)
                return self.reporter.passed("BUTTON_BUZZER", "beep")
        sleep_ms(20)

    return self.reporter.failed("BUTTON_BUZZER", "timeout")
```

这个函数需要文件顶部已有：

```python
from lib.kit.compat import sleep_ms, ticks_diff, ticks_ms
from lib.kit.io_tests import Buzzer
```

## 21. 初学者最容易犯的错误

### 忘记缩进

错误：

```python
def test():
print("hello")
```

正确：

```python
def test():
    print("hello")
```

### 字符串忘记加引号

错误：

```python
app.run(adc)
```

正确：

```python
app.run("adc")
```

### 忘记导入函数

如果用了 `sleep_ms`，顶部要写：

```python
from lib.kit.compat import sleep_ms
```

### 打开 PWM 后忘记关闭

PWM、蜂鸣器、音频这类有输出的功能，最好用 `try/finally`：

```python
try:
    pwm.start()
finally:
    pwm.stop()
```

### 直接改底层库

初学者不要一上来就改 `lib/kit/`。优先在 `universal_main.py` 里写自己的 `cmd_xxx` 函数。

## LCD 行列显示、串口选择和 main.py 轮询

LCD 可以显示文字，也可以显示变量：

```python
showlcd(文字或变量, 行数, 列数)
```

`行数` 和 `列数` 都从 `0` 开始。文字会从你选中的行、列位置开始打印：

```python
from easy_api import *

lcd(1)
guangmin(1)
clearlcd()

i = readguangmin()
showlcd("Light:", 0, 0)
showlcd(i, 0, 8)      # 从第 0 行第 8 列开始显示变量 i
showlcd("OK", 2, 5)
```

串口读写前，先决定使用哪个 UART 和波特率：

```python
setuart(2, 115200)
senduart(b"hello")
data = readuart()       # 立即读取当前已有数据
data = waituart(5000)   # 最多等待 5 秒
```

持续轮询不要写成 `easy_api.py` 里的新函数。比赛时把循环写在 `starter/main.py` 的 `main()` 函数中：

```python
from easy_api import *

def main():
    init()
    lcd(1)
    anjian(1)

    while True:
        event = readanjian()
        if event:
            name, action = event
            clearlcd()
            showlcd(name, 0, 0)
            showlcd(action, 1, 0)
        delay(50)

main()
```
