# 零基础一小时测试指南

这份指南面向没有学过 Python、没有开发过这块板子的用户。你只需要修改
`competition-offline-kit/starter/main.py` 里的参数区、模块启停区和用户功能区，
然后烧录到板子。

重点：真正的硬件函数只有 `easy_api.py` 里的接口。`main.py` 只负责把这些接口组合起来，
除了 `main()` 入口外，不再定义 `serial_title`、`safe_call`、`show_page` 这类容易误认为接口的函数。

## 1. 先记住一条规则

`api.xxx(...)` 表示调用 `easy_api.py` 的真实接口，例如：

```python
api.guangmin(1)             # 开启光敏
i = api.readguangmin()      # 读取光敏
api.showlcd(i, 0, 0)        # 显示到 LCD
```

启停功能只用这一套写法：

```python
api.guangmin(1)             # 1 表示开启
api.guangmin(0)             # 0 表示关闭
```

不要再写 `USE_LIGHT = True`、`USE_LCD = True` 这类二级开关；要开哪个模块，就直接把对应的
`api.xxx(1)` 改成 `api.xxx(0)` 或 `api.xxx(1)`。

## 2. 先改参数区

打开：

```text
competition-offline-kit/starter/main.py
```

参数区通常只需要改轮询速度和串口：

```python
DISPLAY_CYCLES = None
REFRESH_MS = 1000
UART_ID = 2
UART_BAUDRATE = 115200
UART_TIMEOUT_MS = 1000
UART_MIRROR_TO_PC = True
```

`DISPLAY_CYCLES = None` 表示一直刷新；`REFRESH_MS = 1000` 表示每 1000 毫秒刷新一次。
`UART_ID`、`UART_BAUDRATE`、`UART_TIMEOUT_MS` 会传给真实接口；`UART_MIRROR_TO_PC = True` 表示 `api.senduart(...)` 会同时发到外接 UART 和电脑 USB/REPL 串口，方便电脑串口工具同步查看。如需关闭，把 `starter/config.py` 里的 `UART_MIRROR_TO_PC` 改成 `False`。

```python
api.setuart(UART_ID, UART_BAUDRATE, UART_TIMEOUT_MS)
```

如果做 UART 回环测试，用杜邦线连接所选 UART 的 TX 和 RX。

## 3. 再改模块启停区

模块启停区就是比赛现场最常改的地方。`1` 表示开启，`0` 表示关闭：

```python
api.lcd(1)                  # LCD；开启后可用 api.showlcd(...)
api.guangmin(1)             # 光敏；开启后可用 api.readguangmin()
api.wenhumi(1)              # 温湿度；开启后可用 api.readwendu() / api.readshidu()
api.jiasudu(1)              # 加速度；开启后可用 api.readx() / api.readyaxis() / api.readz()
api.gpio(1)                 # GPIO；开启后可用 api.readgpio(...) / api.setgpio(...)
api.uart(1)                 # 串口；开启后可用 api.senduart(...) / api.readuart()
api.lte(1)                  # 4G/LTE；开启后可用 api.readlte()
api.ble(1)                  # BLE；开启后可用 api.readble() / api.sendble(...)
api.gnss(1)                 # GNSS；开启后可用 api.readgnsslat() / api.readgnsslon()
api.lbs(1)                  # LBS；GNSS 没有坐标时作为备用定位
```

如果题目不需要某个模块，直接改成 `0`：

```python
api.spi(0)
api.rs485(0)
```

4G 不能写成 `api.4G(1)` 或 `4G(1)`，因为 Python 函数名不能以数字开头。正确写法是：

```python
api.lte(1)
api.g4(1)
```

通信模块读取示例：

```python
lte_data = api.readlte()
ble_data = api.readble()
location = api.readlocation()  # 优先 GNSS；GNSS 没有坐标时自动使用 LBS
lat = location.get("latitude") if location else None
lon = location.get("longitude") if location else None
api.sendble("hello")
```

GNSS 没有定位时会返回 `None`；启用 LBS 后可用 `readlocation()` 自动回退。BLE 没有手机连接时也可以先广播等待连接。

## 4. GPIO 怎么写

GPIO 输入直接写在用户功能区里：

```python
if api.readgpio("D3") == 1:
    api.setled("red", 1)
    api.senduart("red on\r\n")
```

注意两点：

- 判断相等用 `==`，不是 `=`。
- 字符串引脚名要加引号，例如 `"D3"`。

GPIO 输出也直接调用真实接口：

```python
api.setgpio("D2", 1)
api.setgpio("D2", 0)
```

## 5. LCD 怎么写

LCD 显示部分保持最直观的写法：先写标题，再把值放到标题后面。

```python
api.showlcd("Light:", 0, 0)
api.showlcd(guangmin_value, 0, 7)
api.showlcd("T:", 1, 0)
api.showlcd(wendu, 1, 3)
```

三个参数分别是：

- 第 1 个：要显示的文字或变量。
- 第 2 个：行号，从 `0` 开始。
- 第 3 个：列号，从 `0` 开始。

如果显示内容需要刷新，放在 `while` 轮询里；不要把轮询逻辑封装进 `easy_api.py`。

## 6. 串口怎么写

串口发送保持“标题 + 数值”的逐项写法，零基础用户最容易照着改：

```python
api.senduart("Light:")
api.senduart(guangmin_value)
api.senduart(" T:")
api.senduart(wendu)
api.senduart("\r\n")
```

每轮最后发送 `"\r\n"`，串口助手里会自动换行，更容易看清每一轮数据。

串口读取写在轮询读取区：

```python
uart_read_text = api.readuart()
```

## 7. 用户功能区怎么写

比赛现场新增逻辑优先写在 `main.py` 的“可能的用户写功能区”。例如，D3 输入为 1 时亮红灯：

```python
if api.readgpio("D3") == 1:
    api.setled("red", 1)
    api.senduart("red on\r\n")
    api.after(1000, lambda: api.setled("red", 0))
    api.senduart("red off\r\n")
```

按键事件可以这样写：

```python
event = api.readanjian()
if event:
    name, action = event
    if name == "up" and action == "press":
        api.senduart("up press\r\n")
```

当前 `api.after(...)` 是“延时后执行”的接口；如果后续需要真正非阻塞定时，应把能力封装进
`easy_api.py`，不要在 `main.py` 里自创一套定时器框架。

## 8. 烧录和判断成功

烧录到开发板根目录：

```text
/flash/main.py
```

上电后观察三件事：

1. LCD 是否持续显示 `Light:`、`T:`、`H:`、`x:`、`y:`、`z:` 等字段。
2. 串口助手是否持续收到 `Light:`、`T:`、`H:` 等逐项数据，并且每轮换行。
3. GPIO、按键、LED 等用户功能区逻辑是否按题目现象触发。

出现错误时，先检查 `api.xxx(1)` 是否开启、接线是否正确、`config.py` 引脚是否配置、串口编号和波特率是否一致。

## 9. 比赛现场修改顺序

1. 改参数区：轮询速度、串口编号、波特率。
2. 改模块启停区：需要的模块写 `1`，不需要的模块写 `0`。
3. 检查 LCD 显示区：保持 `api.showlcd("标题", 行, 列)` + `api.showlcd(变量, 行, 列)`。
4. 检查串口发送区：保持 `api.senduart("标题")` + `api.senduart(变量)`。
5. 在用户功能区写题目要求的 GPIO、LED、按键、蜂鸣器或串口响应逻辑。
6. 检查杜邦线和模块供电。
7. 烧录 `starter/main.py` 为板上的 `/flash/main.py`。
